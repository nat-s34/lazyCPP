# LazyCPP - C++ for lazy people!

LazyCPP is a automation script made in Python, designed for people who are fed up of writing "#include \<iostream>" in every project.

LazyCPP, while intended for use in C++ only, *can* be used in any context that you wish!


## Getting Started

### Prerequisites
To run LazyCPP, you'll need:
* [Python](https://www.python.org/downloads/), preferably the latest version. 
* The pynput package. On Windows, use `py -m pip install pynput`. On macOS/Linux, use `python3 -m pip install pynput`.
