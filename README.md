# LazyCPP - C++ for lazy people!

LazyCPP is a automation script made in Python, designed for people who are fed up of writing "#include \<iostream>" in every project.

LazyCPP, while intended for use in C++ only, *can* be used in any context that you wish!


## Getting Started

### Prerequisites
To run LazyCPP, you'll need:
* [Python](https://www.python.org/downloads/), preferably the latest version. 
* The pynput package. On Windows, use  
`py -m pip install pynput`.  
On macOS/Linux, use  
`python3 -m pip install pynput`.

### Installation and Usage
These installation instructions assume you have Git. If you don't have Git, you can either [install it](https://git-scm.com/), or use the green 'Code' button to download it as a ZIP.

1. Clone the repo:  
`git clone https://github.com/nat-s34/lazyCPP.git`
2. Run the main.py file.  
On Windows, use `py main.py`. On macOS/Linux, use `python3 main.py`.
